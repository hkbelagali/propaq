# `propaq.models`

Compiled surrogate models produced by the surrogate propagators, and the
variational wrapper that lets you evaluate one in terms of the original Qiskit
parameters.

See the [surrogate guide](../guides/surrogate.md).

::: propaq.models
    options:
      members:
        - PauliSurrogateModel
        - MajoranaSurrogateModel
        - VariationalSurrogateModel
